Webmail settings

Local mail backend

The webmail runs against the Rust mail-backend on your own computer. It holds unlocked mail passwords in memory only and talks to your IMAP, POP3 and SMTP servers.

Only plain http:// addresses on this computer are accepted: 127.0.0.1 or localhost, any port. Remote backends are refused: mail passwords travel to this address, and the extension may only connect to this computer.

How to start the backend
  1. Install Rust from rustup.rs (once).
  2. From the project's src folder run one of:
    • Windows: run-backend.bat (or powershell -ExecutionPolicy Bypass -File run-backend.ps1)
    • macOS / Linux: ./run-backend.sh
    • Any system: cargo run --release -p mail-backend
  3. Keep it running while you use the webmail. It listens on 127.0.0.1:48101 by default.
  4. Click Test connection.

Open the webmail

Click the toolbar button, or right-click an email link on any page and choose Compose with Webmail.
